# Define the launch promise

Type: grilling
Status: resolved

## Question

What must be true for Jelly Party 2.0 to count as a production replacement, and which browsers and services are launch-critical?

## Answer

Launch through the existing Chrome, Firefox, and Edge listings. A launch-supported service must pass a real two-peer create, join, play, pause, seek, and chat smoke test on the current versions of all three browsers. YouTube, Netflix, and Jellyfin are release blockers; Disney+, Prime Video, and Vimeo are candidates that become launch-supported only when they pass without disproportionate service-specific work. Other HTML5-video sites are best effort.
